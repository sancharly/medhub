# ADD-023 — Frontend API Client (SI-FE-APICLIENT)

## Responsibility

Hand-written typed `ApiClient` (`frontend/src/api/client.ts`) over the browser `fetch`: session
cookie, CSRF header (`withCsrf`, SR-031.3) and RFC 7807 error handling. Request and response types
are generated from the OpenAPI schema by the dev tool `openapi-typescript` into
`frontend/src/api/generated/`; the client and its methods are not generated.

## Software units (IEC 62304 §5.4.1)

- `U-FEAPI-Client` — hand-written typed client over `fetch` (types generated by `openapi-typescript`);
  cookie/CSRF handling (SR-031.3); RFC 7807 errors.

Class B requires decomposition down to software units, not per-unit detailed design
(§5.4.2–5.4.4 are class C). Each unit above is independently unit-testable and is the granularity
at which unit verification records (TS) are written.
